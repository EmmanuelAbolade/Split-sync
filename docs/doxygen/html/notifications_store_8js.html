◆ recordPaymentSent

export const recordPaymentSent

recordPaymentSent Called when the PAYER marks a payment as sent via an external link (PayPal / Revolut). Uses ONLY the existing notifications collection - no new Firestore collection needed.

Creates two notification documents:

  1. payee notification - type: payment_confirmation_needed, requiresAction: true
  2. payer log entry - type: payment_log, auto-read, tracks status changes

Both documents cross-reference each other via payeeNotifId / payerLogNotifId so that confirm / decline can update both in one operation.

Detailed Description

Utility functions for calculating group expense balances and settlement suggestions.

This module is the financial core of Split-Sync. It implements a greedy two-pointer algorithm to minimise the number of transactions required to settle all debts within a group. It also provides helpers for per-user balance summaries and multi-currency grouping.

function export getUserBalanceSummary ( balances,

Returns a human-readable balance summary for a specific user.

Classifies the user's net balance into one of three states:

  • settled: balance is within +/-0.01 (floating-point safe zero).
  • owed: balance is positive; the user is owed money.
  • owes: balance is negative; the user owes money.
Parameters
{Object}balances - Map of { [userId]: netBalance } from calculateBalances().
{string}userId - UID of the user whose summary is required.
{Array}members - Array of group member objects (reserved for future use).
Returns
{Object} Summary object:
  • {string} status - One of 'settled' | 'owed' | 'owes'.
  • {string} message - Display string for the UI.
  • {number} amount - Absolute balance amount (always non-negative).

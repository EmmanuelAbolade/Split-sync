Detailed Description

AES-256 encryption and IBAN formatting utilities for secure data storage.

This module handles client-side encryption of sensitive financial data (specifically IBAN numbers) before they are written to Firestore. Encryption uses AES-256 via the CryptoJS library. The encryption key is read from an environment variable so it is never hard-coded in the production bundle.

IBAN display helpers (formatting and masking) are also provided for the Payment Settings UI.

export const maskIBAN
Initial value:
= (iban) => {
if (!iban) return '';
const cleanIBAN = iban.replace(/\s/g, '');
if (cleanIBAN.length <= 4) return cleanIBAN;
const countryCode = cleanIBAN.substring(0, 2);
const lastFour = cleanIBAN.substring(cleanIBAN.length - 4);
const middleMask = '*'.repeat(Math.min(cleanIBAN.length - 6, 12));
return `${countryCode}${middleMask}${lastFour}`;
}

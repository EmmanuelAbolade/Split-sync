Detailed Description

Utility functions for generating payment links and retrieving available payment methods.

This module generates deep links for PayPal and Revolut payments, formats SEPA bank transfer information, and determines which payment methods a recipient has configured. All link generation is client-side — no API calls are made to payment providers from this module.

Formats SEPA bank transfer details into a structured object for display.

Returns a plain object containing all the fields a payer needs to initiate a SEPA bank transfer from their own banking application. The reference is always set to 'SplitSync Settlement' for easy identification.

Parameters
{string}recipientName - Full name of the payment recipient.
{string}iban - IBAN of the recipient's bank account.
{string}bic - BIC/SWIFT code of the recipient's bank.
{number}amount - Transfer amount.
{string}[currency='EUR'] - ISO 4217 currency code.
Returns
{Object} Formatted transfer details:
  • {string} recipientName - Recipient full name.
  • {string} iban - IBAN or 'Not provided'.
  • {string} bic - BIC or 'Not provided'.
  • {string} amount - Formatted as '{currency} {amount.toFixed(2)}'.
  • {string} reference - Always 'SplitSync Settlement'.

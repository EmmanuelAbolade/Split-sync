The Problem

Shared money is awkward.
Split-Sync makes it simple.

Existing expense-splitting tools are built primarily for the American market, focusing on Venmo while ignoring SEPA bank transfers and Revolut — the dominant payment methods in Ireland and across the EU.

Split-Sync was designed specifically for European users: full SEPA bank transfer support with IBAN validation across 30+ country formats, Revolut deep links, PayPal integration, and a privacy-preserving contact discovery system that never uploads phone numbers to a server.

Built as a Progressive Web App, it installs on any device without App Store approval, works offline, and delivers a native-quality experience on both mobile and desktop.

Core Features

Built for real groups,
real money, real Settlements.

EU Payment Methods

PayPal, Revolut, and SEPA bank transfer with full IBAN validation across 30+ European countries — unlike American-first competitors.

Smart Settlement Algorithm

A greedy two-pointer algorithm minimises transactions to n−1, reducing a 6-person group from 15 possible payments to just 5.

Security by Design

WebAuthn biometric auth, AES-GCM encrypted IBAN storage, SHA-256 contact hashing, and session timeout — privacy-first throughout.

Receipt Scanning (OCR)

Google Cloud Vision API reads merchant name, total, and date from a photo. Auto-fills the expense form in one tap.

Installable PWA

Installs on any device without App Store approval. Offline-capable via service worker — works without an internet connection.

Built-in AI Assistant

Claude-powered in-app chat assistant proxied via Firebase Cloud Function — API key never exposed to the client.
